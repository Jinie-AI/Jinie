# The Everyday Edit

Generated by Jinie. React Native + Expo SDK 54.

1. Install Node 20.19+ or 22 LTS.
2. `npm install`
3. `npx expo install --fix`
4. `npm start` (Android emulator / matching Expo Go or development build)
5. `npm run web` for browser.

Run `npm run build:web` then `firebase deploy --only hosting --project YOUR_PROJECT` after Firebase login.

Cart and demo COD orders are device-local. No real payment, login, inventory server, or fulfilment is connected. Replace the sample catalog and contact details before publication. Generated native output requires device testing.
